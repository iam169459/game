# Devices Tycoon

Business simulator built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Zustand**.

## Run

```bash
npm install
npm run dev
```

## Stack

- **Zustand** — global game state with `localStorage` persistence (`devices-tycoon-v2`)
- **Tailwind v4** — dark tech UI (Apple × Samsung inspired)
- Responsive sidebar (desktop) + compact nav (mobile)

## Starting conditions

- $50,000 cash
- Garage company (12 fans, 10 reputation)
- 1 production line: "Garage Bench"
